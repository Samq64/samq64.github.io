Welcome to the redesigned site at its new domain: [SamuelQ.dev](/)! It was originally deployed five years ago at `samq64.github.io` using the [Cayman](https://pages-themes.github.io/cayman/) [Jekyll](https://jekyllrb.com/) theme. Since then I have improved my software development skills and my interests have shifted, so I decided to overhaul this site and start a blog.

## Software Stack

Under the hood the site is now built using [Hugo](https://gohugo.io) with a custom theme featuring a [Tokyo Night](https://github.com/tokyo-night/tokyo-night-vscode-theme)-based colour scheme and [Phosphor Icons](https://phosphoricons.com/). Styling is done using vanilla CSS, taking advantage of modern built-in features such as [light-dark()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark) and [nesting](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Nesting_selector). Search is implemented using [Pagefind](https://pagefind.app/).

Most pages are designed to be navigated easily in a terminal web browser. The exceptions are pages that require JavaScript, such as search and client-side tools.

## Migrated Projects

The [Windows Update Simulator](/projects/win10-update/) has been ported over, along with the [YouTube RSS Feed Generator](/projects/youtube-rss/) (with a colour palette swap). The [Bliss Board](/projects/bliss/) previously existed in its own repository and has been merged into this site with a redesign.

## Future Plans

I plan on writing about interesting software I find, desktop Linux, and software development tips going forward, so feel free to subscribe via RSS.

{{- /* A content-hashed URL for one of a page bundle's own scripts or stylesheets. The plain filenames are cached for four hours while the HTML around them is only cached for ten minutes, so a deploy could otherwise hand a visitor new markup driven by the previous script. Only what is named here is hashed. A script's own imports keep their filenames, since the hashed name still sits in the bundle's directory for them to resolve against. Takes a dict of "page" and "name". Used by the asset shortcode and by the service worker, which has to precache the very same URLs the page asks for. */ -}} {{- $page := .page -}} {{- $name := .name -}} {{- $resource := $page.Resources.Get $name -}} {{- if not $resource -}} {{- errorf "Asset not found on %s: %s" $page.Path $name -}} {{- end -}} {{- return (fingerprint $resource).RelPermalink -}}

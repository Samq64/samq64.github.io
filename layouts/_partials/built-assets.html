{{- /* A page's own stylesheets and scripts, named by styles and scripts lists in front matter and returned built, as a dict of two slices. Both callers want both lists: page-assets emits them, and the service worker precaches them by the same hashed URLs the page loads, so this is the only place either pipeline is spelled out. Scripts are bundled, which is what folds a script's imports into it, so what a page loads is one file whose hash covers everything it pulls in — only possible from assets, where esbuild can resolve them. The bundles are iife, so they need deferring rather than a module type, and nothing they declare reaches the page. Neither project relies on that, having no inline handlers. */ -}} {{- $styles := slice -}} {{- range .Params.styles -}} {{- with resources.Get . -}} {{- $styles = $styles | append (. | minify | fingerprint) -}} {{- else -}} {{- errorf "Stylesheet not found in assets: %s" . -}} {{- end -}} {{- end -}} {{- $scripts := slice -}} {{- range .Params.scripts -}} {{- with resources.Get . -}} {{- $scripts = $scripts | append (. | js.Build (dict "minify" true) | fingerprint) -}} {{- else -}} {{- errorf "Script not found in assets: %s" . -}} {{- end -}} {{- end -}} {{- return dict "styles" $styles "scripts" $scripts -}}

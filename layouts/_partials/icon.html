{{- /* A name turns the icon into a labelled one. The label is real text rather than an aria attribute, kept inside the same span as the artwork so that a rule hiding one icon of a pair hides its label with it. A browser that draws no SVG and reads no ARIA — a terminal one — is then still left with something to read, which an icon-only link otherwise is not. */ -}} {{- $iconPath := printf "img/icons/%s.svg" .icon -}} {{- with resources.Get $iconPath -}} {{- .Content | safeHTML -}} {{- with $.name }}{{ . }}{{ end -}} {{- else -}} {{ errorf "Icon not found in assets: %s" $iconPath }} {{- end -}}

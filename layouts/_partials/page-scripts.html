{{- /* A page's own scripts, named by a scripts list in front matter and returned built. Bundling is what folds a script's imports into it, so what a page loads is one file whose hash covers everything it pulls in — which is only possible from assets, where esbuild can resolve them. The bundles are iife, so they need deferring rather than a module type, and nothing they declare reaches the page. Neither project relies on that, having no inline handlers. */ -}} {{- $scripts := slice -}} {{- range .Params.scripts -}} {{- $file := resources.Get . -}} {{- if not $file -}} {{- errorf "Script not found in assets: %s" . -}} {{- end -}} {{- $scripts = $scripts | append ($file | js.Build (dict "minify" true) | fingerprint) -}} {{- end -}} {{- return $scripts -}}
